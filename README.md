# A File Manager tap

Self-hosted Homebrew tap for [A File Manager](https://github.com/awamwang/a-file-manager).

## Install

```sh
brew install --cask awamwang/tap/a-file-manager
```

The fully qualified name installs only this cask and trusts only this cask
(Homebrew 6+ requires explicit trust for third-party taps).

```sh
brew upgrade --cask a-file-manager
brew uninstall --cask a-file-manager
```

## Why a self-hosted tap

A File Manager currently ships **ad-hoc signed** macOS builds: there is no
Developer ID certificate or notarization. Official `homebrew/cask` no longer
accepts casks that fail Gatekeeper checks, so the cask lives here instead.

This cask clears `com.apple.quarantine` from the installed app in
`postflight_steps` (the Homebrew 7 declarative install-step syntax), so the
first double-click works on macOS 15+ without the System Settings fallback.
That means the cask deliberately skips one Gatekeeper check on your behalf —
install it only if you trust the upstream GitHub repository and its Releases.

Release assets are published at
<https://github.com/awamwang/a-file-manager/releases> and every release updates
this cask's `version` and per-architecture `sha256` automatically.

## Maintenance

`Casks/a-file-manager.rb` is generated by the upstream Release workflow from
`packaging/homebrew-tap/a-file-manager.rb.tmpl`. Do not edit it by hand here;
changes will be overwritten by the next release.
